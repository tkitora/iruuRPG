# 管理者の図鑑 (`/iruurpg dictionary`、`/iruurpg dic`。t254)

管理者 (`iruurpg.admin`) だけが開けるメニューです。ゲームのアイテム・mob・ファストトラベルの地点を一覧で見て、その場で使います。`gui/DictionaryMenu`。

## ページ
| ページ | 中身 | クリック |
|---|---|---|
| アイテム | `items/*.yml` のアイテム全部。並びは種類 → 必要レベル → レア度 → id | 左クリックで 1 個、Shift+左クリックで 64 個 (重ならないもの、武器・防具は 1 個)。手持ちがいっぱいなら足もとに落ちる |
| mob | `mobs/*.yml` の mob 全部。並びはレベル → id。名前が赤いのはダンジョンのボス | 左クリックで目の前に 1 体、Shift+左クリックで 5 体 (`/iruurpg mob` と同じ出し方) |
| ファストトラベル | `travel/waypoints.yml` の地点全部 (見つけていないものも) | クリックですぐ飛ぶ。演出・待ち時間・費用・発見済みかどうかの確かめは、どれもなし |
| 自分の地点 | その管理者だけの地点 (45 か所まで) | クリックですぐ飛ぶ / Shift+右クリックで消す /「ここを追加」で、今いる場所をチャットに打った名前で残す |

## 絞り込みと検索
- アイテム: 「種類」(全部 / 武器 (近接・遠距離・設置) / 防具 / 素材 / その他)、「レア度」(全部 / コモン〜ミシック)。種類はアイテムに書かれる言葉 (物理・魔法 + 近接・遠距離・設置、防具、素材) で分ける。
- mob: 「いる場所」(全部 / ボスだけ / 場所なし / mob の `areas` のそれぞれ)。ボスは、ダンジョンの `boss` に書かれた mob。
- 検索 (アイテム・mob): 看板をクリックして、チャットに言葉を打つ。名前か id にその言葉を含むものだけ (空白で区切ると、全部を含むもの。全角・半角、大文字・小文字は同じ。色の記号は見ない)。右クリックで検索をやめる。60 秒以内に打つ。「キャンセル」でやめる。

## 自分の地点の保存
- `plugins/iruuRPG/travel/personal-points.yml` に、`players.<uuid>: [{name, world, x, y, z, yaw, pitch}]` で残る。変えるたびに全部を書き直す (一時ファイルを経由)。
- 読めないファイルは書き直さない (警告を出し、地点は空で始める。中身は失われない)。

# ペイントブラシ (`/ibrush`)

建築用のツール (管理者のみ)。ゲームの処理とは別で、`tools/brush` の中だけで動きます。描画は FastAsyncWorldEdit 経由なので、`//undo` / `//redo` で戻せます
(地形を盛る・削る・ならすのは WorldEdit のコマンドで行ってください。ブラシにはありません)。

## 使い方
| 操作 | 内容 |
|---|---|
| `/ibrush give` | ブラシ (アイテム) を受け取る |
| 右クリック | 見ている所に使う (押しつづけると続けて使う) |
| Shift + 右クリック | 1回だけ、結果をプレビューする (自分にだけ見える) |
| 左クリック | 設定画面を開く |
| `/ibrush help [コマンド名]` | コマンドと引数の一覧 |

## 設定画面
上のタブでページを切り替えます。下の行は共通です (閉じる / プレビュー / ブラシをもらう / 元に戻す / やり直し)。
自分のインベントリのブロックをクリックすると、開いているページ (模様・マスク・ブラックリスト) に足せます。

- **基本**: モード (塗る / 自動陰影)、半径、強さ、縁のぼかし、表面だけ、**形**、ノイズ。
- **模様**:
  - *ブロックの割合*: 選んだブロックを割合でばらまく。
  - *グラデーション*: 最初と最後の2ブロックを選ぶと、間を近い色のブロックでつなぐ。間の数、**向き** (中心→縁 / 下→上 / 向きに沿って / ノイズ)、ざらつき。
  - *加算*: オンにすると、同じ所に塗り重ねるたびに、いまの色がグラデーションの方へ少しずつ進む (上乗せ)。
  - *プリセット*: すぐ使えるグラデーション。自分で作ったものは `brush.yml` に残る。
- **マスク**: ブロック・角度・影で、効く場所を絞る (それぞれ逆マスクあり)。影はトゥーン調の段でも絞れる。
- **陰影**: 太陽の向きと高さ、陰の濃さ、影を落とすか、**トゥーン調** (影を段で区切る)。そして**影の源**を足し合わせられる:
  - **光(太陽)**: 太陽の向きと、遮る物による影。
  - **アンビエント(AO)**: まわりを囲まれた所 (くぼみ・隅・壁ぎわ) ほど暗い。
  - **曲率**: 凹み (割れ目・隅) か、出っぱり (稜線・角) を暗くする。岩肌の表現に。
  - **ノイズ**: 滑らかなノイズの斑。汚れ・むら。
  - **セル**: 細胞状 (ボロノイ) の模様。境目を暗くすると、ひび・石畳・鱗の見た目に。
  源はぜんぶ「陰影のマスク」にも効く。選択ツールの「選択範囲に自動陰影」(`/ibrush select shade`) で、選んだ範囲全体に同じ設定で使える。
- **ブラックリスト**: グラデーションの途中にも、自動陰影の暗いブロックにも使わないブロック。全員共通で、「保存」で `brush.yml` に書く。

## なぞる (長押し)
右クリックを押したままブラシを動かすと、使った場所と場所の間も、半径の6割ごとに点をおいて**間を埋めます** (速く動かしても隙間ができない)。グラデーションの向きを
「なぞった線に沿って」にすると、なぞった長さ (`brush.stroke-length`、既定24ブロック) で最初のブロック→最後のブロックになります。

## 選択ツール
別のアイテム (**ブレイズロッド**、`/ibrush select give` か画面の「選択」ページ)。選んだ範囲は**ブラシに効きます** (ブラシは選んだ所だけ。反転すると、選んだ所の外だけ)。

| 操作 | 内容 |
|---|---|
| 右クリック | 見ているブロックから選ぶ (選択を置き換える) |
| Shift + 右クリック | いまの選択に足す |
| 左クリック | 選択の設定画面 (ブラシの画面の「選択」ページ) |

- **ファジー**: クリックしたブロックと色が似ていて、つながった**表面**のブロックを選ぶ。**しきい値** (0〜100) が大きいほど色が離れたブロックも選ぶ。半径は最大64。
- **隣接**: クリックしたブロックと**同じ種類**でつながったブロックを選ぶ (表面だけ / 中も、を選べる)。
- **反転**: 選択を作り直さず、判定を逆にするだけ (選択が大きくても重くならない)。
- **表示**: 選択の**縁**だけを、近く (既定20ブロック) に最大800個の粒子で見せる (自分にだけ)。水色=選択、橙=反転中。
- **ぼかし**: 選んだ範囲の色を、まわり (3x3x3) の平均になじませる。範囲の中にあるブロックだけを使い、`//undo` で戻せる。反転中は使えない。
- 探すのは数tickに分けて行い (1tickに2万ブロック)、新しく選ぶと前の探索は止まる。多すぎると途中で止める (`brush.selection.max-blocks`)。

## 形
球 / 半球 / 円盤 / 円柱 / 輪 / 立方体 / 円錐 / ひし形 / スプレー (中心ほど濃い) / スプラッター (しぶき) / 不定形 (うねる輪郭)。

## プレビュー
画面の「プレビュー」または `/ibrush preview` で追従プレビューになります。見ている所に使った結果が、**あなたにだけ**見えます (世界は変わりません)。
設定を変えるか、見ている所を動かして、0.75秒そのままにすると更新されます。半径が大きいと (既定 16 まで) 使えません。

## `brush.yml` (`plugins/iruuRPG/`)
```yaml
gradient-blacklist: [MYCELIUM, GLOWSTONE]   # グラデーションと自動陰影で使わないブロック
presets:
  my-1: { from: STONE, to: DEEPSLATE, steps: 4 }
```

## 設定 (`config.yml` の `brush:`)
`max-radius` `max-blocks` `range` `cooldown-ticks` `preview-blocks` `preview-ticks` `preview-delay-ticks` `preview-max-radius` `stroke-length` `selection.{max-radius,max-blocks,blocks-per-tick,display-range,display-particles}`

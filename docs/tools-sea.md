# 自分にだけ見える海 (`/iruurpg sea`、t302・t304)

浜辺や港を建てるときに、海の高さを見ながら作るための道具です (管理者のみ)。
決めた高さの**空気のブロックにだけ**水を置いたように見せます。見えるのはその人のクライアントだけです。
ワールドは何も変わらず、ほかの人には見えません。ほかのブロックは上書きしません。

| コマンド | 内容 |
|---|---|
| `/iruurpg sea <y>` | 海の高さを y にして見せる (`~` で自分の足の高さ、`~-3` で足の 3 下) |
| `/iruurpg sea true` / `false` | 見せる / 消す (高さは覚えている。決めていなければ y=81) |
| `/iruurpg sea` | いまの状態 |

## 見え方 (t304)
- **範囲:** 自分のいるチャンクから、縦横 6 チャンクずつの**正方形** (13×13 チャンク) です。
  - その高さの空気に、近いチャンクから順に、1 秒に 16 チャンクずつ水を置きます。
  - config の `sea.chunks` (1〜12) と `sea.chunks-per-update` (1〜64) で変えられます (書いていなければ 6 と 16)。
- **範囲の外へ出たとき:** 一度置いた水は、範囲から外れても**そのまま残ります** (クライアントだけの「ゴーストブロック」)。
  - 行った所には、海が残って見えます。
  - そのチャンクがクライアントに送り直されると、消えます。範囲の中なら、そのとき置き直します。
- **消すとき:** `false` (や高さの変更) で、まわり 6 チャンクの水を、近い所から少しずつ消していきます (本物のブロックを送り直す)。
  - その外に残った水は、チャンクを読み直すと消えます (遠くへ行って戻る、再ログインなど)。
- **ブロックを置いたとき:** その高さにブロックを置くと、そこはブロックになります。
- **記憶の長さ:** ログアウトやワールドの移動までは覚えています。再起動では消えます。
- **実装:** `tools/sea/SeaView`。

# 自分にだけ見える海 (`/iruurpg sea`、t302)

浜辺や港を建てるときに、海の高さを見ながら作るための道具です (管理者のみ)。
決めた高さの**空気のブロックにだけ**水を置いたように見せます。見えるのはその人のクライアントだけです。
ワールドは何も変わらず、ほかの人には見えません。ほかのブロックは上書きしません。

| コマンド | 内容 |
|---|---|
| `/iruurpg sea <y>` | 海の高さを y にして見せる (`~` で自分の足の高さ、`~-3` で足の 3 下) |
| `/iruurpg sea true` / `false` | 見せる / 消す (高さは覚えている) |
| `/iruurpg sea` | いまの状態 |

## 見え方
- **範囲:** まわり 48 ブロック (円) の、その高さの空気だけに水が見えます。動くとついてきます。
  - 0.5 秒ごとに、近づいた所へ水を送ります。離れた所には、本物のブロックを送り戻します。
  - 範囲は config の `sea.radius` で変えられます (8〜96。書いていなければ 48)。
- **ブロックを置いたとき:** その高さにブロックを置くと、そこはブロックになります。壊して空気に戻ると、次の更新で水になります。
- **チャンクを読み直したとき:** 遠くへ行って戻るなど、チャンクが送り直されると水は消えます。そのときは次の更新でもう一度送ります。
- **記憶の長さ:** ログアウトやワールドの移動までは覚えています。再起動では消えます。
- **実装:** `tools/sea/SeaView`。

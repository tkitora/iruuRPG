# プロシージャルツール (`/proceduraltool`、別名 `/treetool` `/ptree` `/ptool`)

建築用のツール (管理者のみ)。以前の「木のツール」を、木だけでなく**いろいろなものを手続き的に作る**ツールにしたものです。アイテムは同じ1つ (サクラの苗木) で、
画面の「作るもの」で切り替えます。`tools/procedural` の中だけで動き、置くときは FastAsyncWorldEdit 経由なので `//undo` / `//redo` で戻せます。

## 使い方
| 操作 | 内容 |
|---|---|
| `/proceduraltool` | ツールを受け取る |
| ブロックをクリック | そこに置くものの設定画面を開く (置き場所は、クリックしたブロックの真上。逆さのスパイク・結晶は真下) |
| 空中を右クリック | 前回の場所の設定画面 |
| 画面の「プレビュー」/ `/proceduraltool preview` | あなたにだけ見えるガラスの試し置き (設定を変えて 0.75 秒後に更新、シード固定) |
| 画面の「生成する」 | 置く (部位ごとの色のウール。あとで本物のブロックに変える) |
| `//undo` `//redo` | 置いたものを戻す / やり直す |

## 作るもの (画面の「作るもの」、`/proceduraltool kind <名前>`)
| 種類 | 内容 | 主な設定 |
|---|---|---|
| 木 (`tree`) | 幹・枝・葉。アルゴリズム5種、樹冠の形、幹の分岐・傾き・ねじれ・ふくらみ、枝の長さ・太さ、根は地形に沿う | 高さ・幅・幹・枝・葉のページ |
| 岩 (`rock`) | ごつごつした岩。数を増やすと大小のかたまり。層 (明暗の縞)・苔 | 数・荒さ・層の数・苔 |
| スパイク (`spike`) | 地面から生える尖った柱 (石筍・棘・杭)。**逆さ**にするとつらら (クリックしたブロックの下に垂れる) | 数・荒さ・先の細さ・傾きのばらつき・曲がり・層・逆さ |
| 結晶 (`crystal`) | 岩の根元から外へ向かって生える結晶のかたまり (芯つき) | 数・荒さ・先の細さ・傾きのばらつき・逆さ |
| 柱状節理 (`columns`) | 六角形に並ぶ玄武岩のような柱の岩場 (中心が高く、縁は低い) | 荒さ・層の数 |
| アーチ (`arch`) | 二本の脚をつなぐ自然の岩のアーチ (向きはランダム) | 荒さ・層の数・苔 |

種類を切り替えると、大きさや数などが**その種類の初期値**になります。部位 (ウールの色) は種類ごとに違い、設定ファイル `treetool.materials` で別のブロックに変えられます。

## 共通
- 置くのは空気と草花だけ (地形は置き換えない)。岩・スパイクなどは、地形の斜面に合わせて、足元を地面まで伸ばします。
- 設定の保存は `/proceduraltool save <名前>` (画面からは保存できません)、読み込みは画面か `/proceduraltool load <名前>`。保存した「作るもの」も一緒に残ります。
- 設定 (`config.yml` の `treetool:`): `max-blocks` `blocks-per-tick` `replace-solid` `max-height` `max-width` `preview-delay-ticks` `preview-blocks-per-tick` `preview-max-blocks` `materials.*`。

## 足していくには
新しい種類は、`ProcKind` に項目と部位を足し、`ProceduralShapes` に作る関数を足すだけで、プレビュー・置く・undo・保存・画面の切り替えが共通で使えます。

# プロシージャルツール (`/proceduraltool`、別名 `/treetool` `/ptree` `/ptool`)

建築用のツール (管理者のみ)。以前の「木のツール」を、木だけでなく**いろいろなものを手続き的に作る**ツールにしたものです。アイテムは同じ1つ (サクラの苗木) で、
画面の「作るもの」で切り替えます。`tools/procedural` の中だけで動き、置くときは FastAsyncWorldEdit 経由なので `//undo` / `//redo` で戻せます。

## 使い方
| 操作 | 内容 |
|---|---|
| `/proceduraltool` | ツールを受け取る |
| ブロックをクリック | そこに置くものの設定画面を開く (置き場所は、木・岩はクリックしたブロックの真上、スパイク・結晶はクリックした面) |
| 空中を右クリック | 前回の場所の設定画面 |
| 画面の「プレビュー」/ `/proceduraltool preview` | あなたにだけ見える試し置き (選んだブロックのまま。設定を変えて 0.75 秒後に更新、シード固定) |
| 画面の「生成する」 | 置く (部位ごとに選んだブロックで) |
| 画面の部位のアイコンを左クリック → 自分のインベントリのブロックをクリック | その部位のブロックを選ぶ (右クリックで初期値に戻す)。`/proceduraltool block <部位> <ブロック名\|hand\|reset>` でも選べる |
| `//undo` `//redo` | 置いたものを戻す / やり直す |

## 作るもの (画面の「作るもの」、`/proceduraltool kind <名前>`)
| 種類 | 内容 | 主な設定 |
|---|---|---|
| 木 (`tree`) | 幹・枝・根・葉 (・雪)。アルゴリズムは **樹冠 / 段の枝 / ヤシ** の3つ (下を参照)。大きさは木の数字で決まる (高さ・幅の箱はない) | 幹・根 / 枝 / 葉 のページ (アルゴリズムごとに中身が違う) |
| 岩 (`rock`) | ごつごつした岩。数を増やすと大小のかたまり。層 (明暗の縞)・苔 | 数・荒さ・層の数・苔 |
| スパイク (`spike`) | **1本**の尖った柱。**見ているブロックの面から、あなた(視点)の方へ向かって**生える | 角の数・ねじれ・筋の深さ・先の細さ・曲がり・荒さ・層 (専用の「形」ページ) |
| 結晶 (`crystal`) | 見ているブロックの面から、あなたの方へ向かって生える。**作り方を選べる**: かたまり / 大きな1本 / 薄い刃 | 数・面の数・先の長さ・太さ・長さのばらつき・傾き・荒さ (専用の「形」ページ) |
| 家の土台 (`house`) | 家の骨組み (柱・壁・床・屋根・石) を**ウール**で (材質は決めない。形だけのブロックアウト)。クリックしたブロックの上に、**正面があなた(視点)の方を向いて**建ち (4方向のいちばん近い向き)、そこから**回転**できる。ドーマー窓・煙突・塔などの**追加パーツ**を、土台を書き換えずに足せる。**おまかせ生成**で、パターンの決まりに沿って全部をランダムに組み合わせられる | 「形」(幅・奥行き・階数・1階の高さ・柱の間隔・柱を両端から・回転・張り出し・4方向・持ち送り・入口・基礎・土台の高さ・土台のテラス) /「壁」(石の1階・石の基壇・木組み・壁を奥へ・窓・窓ガラス) /「屋根」(形・勾配・軒の出・棟の向き・棟木・階の間の庇・段) /「追加パーツ」/「おまかせ生成」 |
| ロビー (`lobby`) | t190。中央の広場 (床の模様・噴水か台座・花壇) のまわりに、おまかせ生成の家を広場へ向けて、大きさ・距離・角度・間隔を少しずつ変えて並べる。家への道・すきまの木・地形へのなじませも (下の「ロビー」) | 「形」(広場の半径・形・家の数・広場から家まで・ばらつき・中央・花壇の数・木の数・家への道・地形になじませる・家のパターン・パーツの多さ) |
| クモの巣 (`web`) | **ツールでブロックをクリックして点を2つ以上選び**(クリックした面の先の空気が点になる。Shift+クリックで最後の点を消す、画面か `/proceduraltool point <clear\|undo\|shape>`)、点の間とまわりの地形に合わせて巣を張る。**巣の形**: 円網 / 棚網 / 皿網 / 漏斗網 / 不規則網 / 条網 | 糸の段数・放射糸の数・たるみ・不規則さ・地形を探す距離 (専用の「形」ページ) |

クモの巣は**空気にしか置かない**(プレビューも生成も、空気以外のブロックは上書きしません)。糸が壁や地面に当たったら、そこで止めてその面を「点」として扱い(糸が壁の向こうで出てきたら、そこからまた張る)、点のまわりの壁・地面・天井(地形を探す距離まで)にも糸を固定します。糸は本物のクモの巣ブロック(`treetool.materials.web` / `web-frame`)で、プレビューでもクモの巣のまま見えます。設定: `treetool.web-max-points` `web-max-volume`。

スパイクと結晶は、ブロックをクリックした面に生えて、**クリックしたときのあなたの目の方向**を向きます (先端が地面まで引き伸ばされることはありません)。
種類を切り替えると、大きさや数などが**その種類の初期値**になります。部位は種類ごとに違います。部位のブロックは画面かコマンドで選び、設定と一緒に保存されます (選んでいない部位は、設定ファイル `treetool.materials` のブロック)。

## 木のアルゴリズム (t114)
nekorozv の Lua の木のスクリプト3本を移したものです (数字の名前・範囲・初期値はスクリプトのまま)。再帰はスタックのループにしたので、深い設定でも止まりません。ブロックは、スクリプトと同じく、あとから置いたものが前のものを上書きします。

| アルゴリズム | 形 | 主な数字 |
|---|---|---|
| 樹冠 (`canopy`、標準) | 枝が同じ規則で分かれ続けるフラクタル。枝先に葉の塊、根元に根。樹冠を上へ重ねられる (間に幹) | 幹の高さ・最初の長さ/太さ・長さ/太さの倍率・枝分かれの深さ・分岐数・広がり・枝のずれ・樹冠の数/間隔/上の大きさ・ねじれ・中心へ戻す力・根・重力・風。葉: 大きさ・葉の付く深さ・平たく・柳のつる・**ベータ版の葉** (丸太から4ブロックより遠い葉を消す) |
| 段の枝 (`tiered`) | 細る幹に、段ごとに枝 (上ほど短く上向き)。てっぺんに葉の塊5つ、根元に根 | 木の高さ・枝のない幹・太さ・ねじれ (らせん)・**編み込みの幹** (2本がからむ)・根の張り・風。枝: 段の間隔・1段の枝の数・**枝の高さのずれ** (t242。1つの段の枝の付け根を、段の間隔 × この割合の幅で上下にばらし、向きも少し崩す。初期値 0.7、0 で全部同じ高さ)・長さ・垂れ。葉: 大きさ・密度・柳のつる・**雪** (雪の部位のブロック)・雪の量 |
| ヤシ (`palm`) | S字の幹 (二股にもなる)、てっぺんに葉の層。支柱の根 | 幹の高さ・太さ・S字・二股の確率/開き・支柱の根。葉: 層の数・1層の数・長さ・厚み・垂れ・角度 |

- オン/オフの項目 (柳のつる・雪など) は、クリックで切り替わります。
- 部位: 幹・枝・根・葉・雪 (雪は段の枝だけ、枝はヤシにはない)。画面の部位のアイコン → インベントリのブロック、または `/proceduraltool block <部位> <ブロック>` で選びます。**状態つきのブロック**も選べます: `/proceduraltool block branch oak_log[axis=x]`。葉は消えない葉 (persistent) で置きます (状態を書いたときは、その状態)。
- **葉のグラデーション**: 「葉」のページの下の段で、葉のブロックを下から上へ最大6段。葉の塊の中の高さで変わります (ヤシは、葉の付け根が上の段、垂れた先が下の段)。`/proceduraltool block leaf a,b,c` でも。
- **見本の木**: jar に12本入っていて、起動時にまだ入れたことのないものだけ `plugins/iruuRPG/trees/` に入ります (消したり書き換えたりしたものは戻しません。入れた名前は `trees/.samples`)。読み込みは画面の「読み込み」か `/proceduraltool load <名前>`: `canopy_oak` `canopy_willow` `canopy_tiers` `canopy_beta_oak` `canopy_cherry` `tiered_spruce` `tiered_snowy_pine` `tiered_braided` `tiered_weeping` `palm` `palm_twin` `palm_mangrove`。
- 大きい設定は、置くときの上限 (`max-blocks`) とプレビューの上限 (`preview-max-blocks`) で止まります。

## 家の土台 (t179、Houdini の建物ジェネレーターを参考に。t181 で回転・屋根・追加パーツ。t185 でおまかせ生成・段の屋根・1 度の回転。t190 で壁と屋根の奥行き・棟・外階段・塔の形。t239 で物語の家・塔の尖り屋根・形に合わせたパーツ)
nekorozv の依頼「家の基盤を作るツール。材質の設定は要らず、柱・壁・床・屋根をウールで」。t181「回転・ファンタジー寄りの屋根・ドーマー窓などを、プレビューの段階で非破壊的に追加・移動・編集」。t185「複数のパーツを組み合わせた形をランダムに出力 (パターンを選べる)、1 度ごとの回転、1 1 1 2 3 3 3 2 1 1 1 のような鋭く少しカーブする屋根」。t190「複雑な形も家の形のひな型として作れるように。hub build は城館ではなく、ロビー・スポーンの建築スタイル (急勾配の屋根・木組み・石の基礎・奥行きと重なり)」。`HouseShape` (追加パーツは `HouseModule`、おまかせ生成は `HouseDesigner`)。
- **形**: 正面の幅 × 奥行きの四角い床に、決めた階数の階を重ねる。クリックしたブロックがまん中。正面はクリックしたときの視点の方。
  - 各階の床は、その階の足元。
  - 壁は外まわり。
  - 柱は四隅と、壁に沿って「柱の間隔」ごと。0 で四隅だけ。
  - **柱を両端から** (t185): オンにすると、柱の間隔を壁の両端の角から数える (左右対称の柱と窓。窓は柱の間のまん中に、奇数の幅なら 1 (7 以上で 3)、偶数なら 2)。オフは左の角から (これまでどおり)。
- **窓**: 柱と柱の間の壁に、階ごとに 1 つ。壁が 5 ブロック以上なら幅 2。1階の高さが 4 以上のとき。
- **入口**: 正面の 1 階のまん中に、高さ 2 の穴。柱に当たるときは、柱でないいちばん近いブロックへずらす (右が先)。
- **屋根** (「屋根」のページ):
  - 形: 平ら / 切妻 / 寄棟 (4面) / 片流れ (正面が低く、奥が高い。勾配の半分) / 腰折れ (軒側が急で、棟側がゆるい。納屋の屋根) / マンサード (腰折れを4面に。上はほぼ平ら) / 入母屋 (下は寄棟、上に小さな切妻) / 半切妻 (切妻の上の端だけ寄棟) / 反り屋根 (4面とも、軒が反り上がり、上ほど急) / **尖り屋根** (t185、段の切妻) / **尖り寄棟** (t185、段の寄棟)。
  - **屋根の段** (t185、尖り屋根・尖り寄棟のとき「屋根」のページの下に出る): 断面を、軒から棟へ「その列で屋根が何ブロック上がるか」の数の列で決める。初期値は `1 1 1 2 3 3` で、軒の出を含めて 11 列の屋根なら断面が `1 1 1 2 3 3 3 2 1 1 1` (高さ 0 1 2 4 7 10 7 4 2 1 0) になる。
    - 段は最大 12、それぞれ 0〜8。左クリック +1 / 右クリック −1 / Shift+左で複製 / Shift+右で消す / 「＋」で棟の側に足す。最初の段が 2 以上なら、軒がその分だけ下へ垂れる。
    - 「段の形を選ぶ」: 定番の尖り `1 1 1 2 3 3` / 鋭い尖り `1 1 2 2 3 4` / 裾の長い反り `1 1 1 1 2 3` / 垂れた軒 `2 1 1 2 3 3` / 塔のような急勾配 `1 2 3 4 5` / ゆるい反り `1 1 1 1 1 2 2`。
    - 「段を大きさに合わせる」: オンは、段の列を軒から棟までの列の数に伸び縮みさせる (形が保たれる)。オフは、棟から段の列のまま並べ、足りない軒側は最初の段を繰り返す。
    - 「この家の屋根の断面」に、いまの家での段・高さ・断面の絵が出る。
    - コマンド: `/proceduraltool set house-roof-steps 1 1 1 2 3 3` (断面全体 `1 1 1 2 3 3 3 2 1 1 1` を打てば半分にする)。
    - 屋根の厚みはいちばん高い段。段の屋根の家では、ドーマー窓の屋根も段で、塔の円錐は段を 1.5 倍に急にした魔女の帽子の形になる。翼棟の屋根も同じ段。
  - 棟の向き: 自動 (長い辺に沿う) / 正面と平行 (平入り) / 正面と直角 (妻入り: 正面に三角の破風)。片流れは「正面と直角」で横へ流れる。
  - 勾配は、1 ブロック内へ入るごとに上がる高さ。1 で 45 度。屋根の厚みは、いちばん急な所に穴があかないだけ。
  - 軒の出の分だけ、壁の外へ出す。
  - 屋根の下のすきま (切妻の妻壁、片流れの高い側、入母屋・半切妻の小さな破風) は、壁でふさぐ。柱の位置では柱が上まで続く。
  - 平らでない屋根の下には、最上階の天井の床を張る (屋根が下りてきている所は屋根のまま)。
- **回転** (t181、t185 で 1 度ずつ): 正面をこちらに向けたあと、さらに時計回りに回す角度 (上から見て、**1 度ずつ。Shift で 5 度**。359 の次は 0)。追加パーツごと全体が回る。90 の倍数以外では、家の各ブロックをいちばん近い世界のブロックに写し、角だけで接する所を埋めて、屋根の段のすきまを閉じる。窓などの細かい所は、斜めでは形が崩れることがある。
- **上の階の張り出し** (t181): 2階から上は、1階上がるごとに正面と裏へ、決めたブロック数ずつ張り出す (最大 3)。床が外へ出て、その上に壁と柱が立つ。屋根は最上階に合わせる。
- **石の1階** (t181): 1階の壁と柱を「石」の部位 (灰のウール) にする。1階建てなら妻壁も石。
- **木組み** (t181): 石でない階の壁に、床の高さの梁と、柱と柱の間に下から斜めに上がる筋交いを入れる。妻壁の下の段も梁になる。t190 から、梁と筋交いは「梁」の部位 (柱とは別のブロックにできる)。
- **壁の奥行きと重なり** (t190、「壁」「形」「屋根」のページ):
  - 壁を奥へ: 柱と梁の間の壁を 1 ブロック奥へ下げる (各階の足元の段と、天井の高さの段はそのまま)。骨組みが前に出て、壁面に凹凸ができる。
  - 窓ガラス: 窓の穴に「窓」の部位を、壁の面から 1 ブロック奥へ入れる (奥まった窓)。
  - 石の基壇: 1階の壁のまわりに、1 ブロック外へ出た石の段 (高さ 1〜3)。入口の前は足元だけ。基礎があれば地面まで伸びる。
  - 張り出しを4方向に: 上の階の張り出しを、左右にも出す。
  - 持ち送り: 張り出した階の下に、下の階の柱から斜めの支え (梁の部位)。宙に出た棟の下にも。
  - 階の間の庇: 上の階の足元に、壁から外へ出る小さな屋根 (長さ 1〜2、1 ブロック外へ出るごとに 1 下がる。角は寄棟)。張り出しのある面には付けない。
  - 棟木: 屋根の棟の上に梁を通す。切妻の端では破風の先へ 2 ブロック突き出し、先を 1 上げる。
- **基礎**: 地面が低い所では、柱 (石の1階なら石の壁ごと) を地面まで伸ばす (最大 12 ブロック)。追加パーツの柱・煙突・塔も同じ。
- **土台** (t195、「形」のページ): 「土台の高さ」(0〜8) だけ、家全体を石の土台の上に上げる。「土台のテラス」(0〜4) で、土台を壁の外へ広げる。
  - 地面に立つもの (家・1 階の棟・地面からの塔・翼棟・ポーチ・煙突・外階段) の下は、床まで石で埋める。
  - 棟は「床の高さ」で、家の床より上げ下げできる (−8〜8 ブロック)。棟ごとに高さの違う土台に載り、テラスも棟ごとの高さになる。テラスの各列は近い方の棟 (同じなら低い方) の高さなので、棟と棟の間に段ができる。
  - テラスの縁には、横より 2 以上高い所に低い手すり (石) を付ける。
  - 地面より高い床の入口 (家の入口、正面の 1 階の棟の入口) からは、外へ階段を下ろす。入口の前のテラスやポーチの上を進み、その縁から 1 ブロックごとに 1 段下りて地面まで (幅 3)。
  - 土台の下も、基礎があれば地面まで伸びる。土台の高さ 0 で棟も上げ下げしなければ、これまでと同じ。
- **追加パーツ** (t181、「追加パーツ」のページ): 土台を書き換えずに、パーツを足す。リストに最大 12 個。生成のたびに、土台を作ってから、リストの順にパーツを上に作る (後のパーツが前のパーツの上に来る)。パーツが土台にめり込む所は、パーツが勝つ。パーツの中 (ドーマー窓の中・塔の中・翼棟とのつなぎ目・出窓とバルコニーの出入り口) は、土台を開ける。消す・オフにすると、土台は元どおり。
  - 位置: **面** (正面 / 右 / 裏 / 左。右・左は正面から見て)、**横の位置** (その面のまん中から。外からその面を見て右が +)、**壁からの位置** (外へ +、家の中へ −。t185 で ±20 まで: 大きな家のまん中の塔、長い翼棟の先の塔)。
  - 大きさ: 幅 (面に沿って。塔は直径)、奥行き (壁から外へ)、高さ (種類で意味が違う)、階 (塔・バルコニー・出窓が何階から始まるか。0 = 1階)。
  - 棟 (t190): 階と屋根を持つ箱を、好きな位置・高さ・大きさで足す。幅 (面に沿って)・奥行き (壁の線から外へ)・階数・始まる階・屋根の形 (家と同じ、またはほかの形)・棟の向き・張り出しを決められる。窓・木組み・壁の奥行きなどは家と同じ。
    - 家と重なる所は、棟の壁を作らずに家の中とつなげる (棟の角の柱は残す)。棟の中にある家の壁・屋根は取り除くので、家より高い棟は屋根を突き抜ける。
    - 始まる階を上げると、家の上に載る・宙に張り出す (持ち送りがあれば下に支え)。1階で正面に付けた棟には、その正面のまん中に入口が開く。
    - 低い横の棟・正面の破風の棟・上の階から張り出す棟・屋根を突き抜ける棟などを組み合わせて、複雑な形のひな型にできる。
  - 外階段 (t190): 壁に沿って上の階へ上がる石の階段。上に踊り場があり、壁に入口を開ける (壁が奥へ下げてあれば、その壁も)。幅 1〜3、上がる向き (右へ / 左へ)、上がった先の階。上がった先の階が張り出していれば、その下は 1 階の壁まで埋める (t193)。
  - ドーマー窓: 屋根の上、壁の線から奥へ。壁の高さ・小さな切妻屋根・正面に窓。屋根に届くまで奥へ伸び、後ろの屋根は開く。
  - 煙突: 壁の外 (壁からの位置をマイナスで家の中) に、地面から、近くの屋根のいちばん高い所より「高さ」だけ上まで。石。
  - 塔: 丸い塔 (初期値で壁に半分めり込む)。家の壁より「高さ」だけ上まで。階ごとに床、急な円錐の屋根。t193 から壁に窓の穴はあけない (純粋な円柱・八角柱・四角柱)。1階からなら石。階を 1 以上にすると、下が細くなる持ち送りで壁から突き出す小塔。t190 から、形を 丸 / 八角 / 四角 (屋根はピラミッド) にでき、いちばん上の階を 1〜2 張り出せる (下に支え、上は壁)。円錐の急さは、丸が勾配の 2.5 倍、八角が 2 倍、四角が 1.25 倍。
    - **屋根の高さ** (t239): 「家の屋根なり」(上のとおり) / 尖り屋根 低・中・高。尖り屋根は、まっすぐな円錐 (段の屋根の家でも段にしない) で、高さは軒の半径 (塔の半分 + 張り出し + 1) の 2.25 / 3 / 3.75 倍 (塔の幅のおよそ 1.1 / 1.5 / 1.9 倍。四角は 0.8 倍)。保存は `spire` (0〜3)。
  - 翼棟: 横に張り出す棟 (「高さ」= 階数)。屋根は本体と同じ形で、棟が本体と直角 (クロスゲーブル)。本体の屋根の中へ、本体の屋根より上にある所だけ伸びる (谷になる)。つなぎ目の本体の壁は開ける。
  - ポーチ: 壁の前の床、外側の柱 (両端の角と、そこから 4 ブロックごと。左右対称で、まん中 (入口の前) には立てない。t185)、家から外へ下がる片流れの屋根 (「高さ」の所)。
  - バルコニー: 「階」の床の高さから外へ出る床、「高さ」の手すり、下に方杖、壁に出入り口 (2 高さ)。
  - 出窓: 「階」の壁から出る箱。角に柱、ほかの面はガラスの穴、床と屋根、下に持ち送り。部屋の側の壁は開ける。
  - 画面: 上の 2 列がリスト (左クリックで選ぶ、右クリックでオン・オフ、「＋」で足す)。下の 2 列が選んだパーツの数字 (種類・面・横の位置・壁からの位置・幅・奥行き・高さ・階・オン/オフ・左右反転して複製・消す (Shift+クリック))。種類を変えると大きさはその種類の初期値。
  - **重なりの優先度** (t193): パーツの種類ごとの順位 (塔 > 棟・翼棟 > ドーマー窓・煙突 > 出窓・バルコニー・外階段 > ポーチ)。パーツは、自分より上の順位のパーツのブロックを取り除かず、上書きもしない (同じ順位なら後のパーツ)。土台はすべてのパーツより下 (パーツがつながる所は土台を開ける)。重なっても穴があかない。棟の壁は、家の軒の下 (壁の外) でも作る。
  - 保存: `/proceduraltool save` で、設定の `house-modules` (種類・面・位置・大きさ・オン/オフ、t190 から屋根・棟の向き・形・張り出し) に一緒に残る。屋根の段 (`house-roof-steps`)、おまかせ生成の決まり (`house-gen-*`) と seed (`house-design-seed`) も残る。
- **おまかせ生成** (t185、「おまかせ生成」のページ): パターンの決まりに沿って、土台・屋根・追加パーツを組み合わせた家を作る。できた家は、手で作った家と同じ数字の設定 (形・屋根・追加パーツのリスト) なので、気に入ったものをそのまま形・屋根・追加パーツのページで続きを編集できる。
  - **新しい案を出す**: 全部作る。**パーツだけ振り直す**: 土台 (形・屋根) はそのままで、追加パーツだけを作り直す。**◀ 前の案 / 次の案 ▶**: 作った案を行き来する (最大 20。最初の案の前は、使う前の設定。いまの案を手で変えた分は、その案に残る)。
  - パターン:
    - コテージ: 小さな 1〜2 階。急な屋根 (尖り屋根が多い)、煙突、ドーマー窓、入口のポーチ、出窓、たまに片屋根の小さな翼棟。
    - 木組みの町家: 間口が狭く背が高い (2〜4 階)。正面に破風 (妻入り)、上の階の張り出し、木組み、石の1階、上の階ごとの出窓 (重なる出窓)、横の屋根のドーマー窓、バルコニー。
    - L字の農家: 横長の本体の端に、角にそろえた翼棟 (L 字。多いと反対側にも)。煙突・ドーマー窓・ポーチ。
    - 館: 幅の広い左右対称。両端の翼棟 (前へ出す U 字か、横へ伸ばす)、中央のポーチとバルコニー、並んだドーマー窓、両端の煙突、出窓の対。
    - 塔の家: 小さめの本体の角に、屋根より高い丸塔 (段の屋根なら魔女の帽子)。別の角に持ち送りの小塔、バルコニー。
    - ハブの家 (t190 で作り直し): ロビー・スポーン (hub) の建築スタイルの家。急で大きな屋根 (腰折れ・尖り屋根・急な切妻)、棟木、階の間の庇、屋根の上の四角い塔 (上の階が張り出し、ピラミッドの屋根: 屋根の重なり)、正面の破風の棟 (入口つき)、石の1階と基壇、木組み、奥まった壁と窓、張り出した上の階と持ち送り、低い横の棟、ドーマー窓。
    - 複合プランの家 (t195): 長方形をいくつも組み合わせた平面 (L 字・T 字・U 字・十字・ずらし) の家。
      - 本体のほかに大きな棟を付ける。棟の幅は本体の奥行きまで (横に向けた破風が本体の棟より低くなる) で、その 2/3 以上。奥行き 5〜9、階数は本体と同じか 1 少ない。
      - 屋根は棟ごとに本体と違う形 (寄棟・半切妻・腰折れ・入母屋・反り屋根・尖り屋根など、できるだけ重ならない)。切妻の仲間は破風を外へ向ける。
      - 床の高さ (土台) は棟ごとに −2〜+2。本体は 75% の確率で土台とテラスに載る。
      - 本体より 1〜2 階高い四角い塔の棟 (寄棟・反り屋根・尖り寄棟の屋根) を本体の角に。棟と本体の内角に丸い塔。棟のない面に片流れの下屋。ポーチ・ドーマー窓・煙突も。
      - 本体の棟より高くしてよいのは、塔の棟だけ。
    - 組み合わせの家 (t190): 高さの違う棟を組み合わせた、家の形のひな型。背の高い本体、低い横の棟、上の階から宙に張り出す棟、細い塔 (丸・八角・四角、上の階が張り出す)、外階段、急な屋根、ドーマー窓、煙突。
    - 物語の家 (t239、nekorozv の参考画像の木組みの家から): 屋根の線が 3 つの高さになり、その上に尖り屋根が立つ家。
      - 本体: 2〜3 階、幅 9〜15・奥行き 7〜11、とても急な屋根 (勾配 1.35〜1.85。尖り屋根が多く、段は軒で反る形が多い)、棟は正面と平行。石の1階・木組み・上の階の張り出しが多い。
      - 正面の破風の棟 (主役): 本体と同じ階数で、棟を正面へ向ける (本体の棟より低い)。入口の上 (棟の入口が家の入口) か、幅 13 以上の家なら正面の端。
      - 塔 (主役): 破風の棟と正面の壁の角に、丸か八角の塔 (幅 5〜7)。壁はまわりの屋根の少し下 (軒より半階以上は上) まで、いちばん上の階は張り出すことが多く、屋根は尖り屋根 (中か高が多い)。尖り屋根の先が本体の棟より 3 以上上に出るまで、屋根を高く、それでも足りなければ壁を高くする。入口をふさぐ側なら反対側へ。狭い家では角の塔になる。
      - ほかに: 破風と反対の横に低い棟、出窓 (1 階と横の 2 階)、片流れの下屋、ポーチ、急なドーマー窓、高い煙突 2 本 (屋根から 3〜6)。左右対称なら、破風は入口の上、塔は両側に対で。
    - おまかせ: 毎回上のどれかを選ぶ。
  - **形もおまかせ** (t193): オフにすると、幅・奥行き・階数・1階の高さ・柱の間隔は今のまま (屋根・外観・パーツは、それぞれのおまかせのとおり)。オンのとき、幅と奥行きは奇数にする (棟が 1 列になり、屋根の頂上が 1 ブロック)。棟・塔・ドーマー窓の幅も奇数。
  - **パーツは形に合わせる** (t239): 追加パーツの大きさと位置は、「規模」ではなく、いまの形 (幅・奥行き・階数・1階の高さ・柱の間隔) と屋根から決める。形もおまかせがオフで手で決めた形でも、「パーツだけ振り直す」でも同じ。
    - 柱の間隔: ドーマー窓は、その下の柱と柱の間の幅 (3〜7、奇数) で、柱と柱の間のまん中に置く。出窓は柱と柱の間の幅 (2〜5。町家の広い出窓は柱をまたいで +2)。バルコニー・ポーチ・棟・翼棟は、柱から柱まで届く幅 ((幅 − 1) が柱の間隔で割り切れる幅) が多い。柱が四隅だけなら、家の幅から。
    - 大きさ: 翼棟・棟が外へ出る長さは、その面から奥への長さ (正面なら奥行き、横なら幅) から。ポーチは柱の間隔の 2 つ分まで (家の幅 − 4 まで)。
    - 高さ: ドーマー窓の壁は 1階の高さ − 2 (2〜4)。煙突は屋根の高さから (急で高い屋根ほど高い。2〜4、物語の家は 3〜6)。
  - **パーツのつながり** (t193): 外階段・バルコニーは、開ける壁があり、その奥が部屋である所にだけ置く。出窓は壁の上に、外の煙突は壁に寄せて、宙の棟・小塔は家かほかのパーツに触れる所にだけ置く。
  - **塔の大きさと高さ** (t193): 塔の家の塔は家の幅の 1/3〜2/3、小塔は 1/3 まで、ハブの家の屋根の上の塔は家に収まる大きさ (いずれも奇数)。高さは、塔のまわり (3 ブロック以内) のいちばん高い所 (家の屋根やほかのパーツ) から、塔の幅の 0.5〜1.6 倍だけ上 (屋根の上の塔は、張り出す上の階がまわりより上に出るように)。
  - 外観もおまかせでは、パターンごとの確率で土台 (高さ 1〜3) とテラス (0〜2) も決める (t195)。
  - 外観もおまかせ (t190) では、パターンごとの確率で、張り出し (4方向)・持ち送り・壁を奥へ・窓ガラス・石の基壇・階の間の庇・棟木も決める。
  - 決まり (数字): **規模** (小・中・大)、**パーツの多さ** (0〜3。おおよそ 2 / 4 / 7 / 10 個。パターンの主役のパーツ (農家の翼棟、塔の家の塔、ハブの翼棟と塔、物語の家の破風の棟と塔) は数えない)、**対称** (パターン次第 / 左右対称 / 崩す)、**塔** (パターン次第 / なし / 少し / 多め)、**重なりの許容** (なし / 少し / 多め)、**屋根もおまかせ** (オフで今の屋根のまま)、**外観もおまかせ** (石の1階・木組み・張り出し。オフで今のまま)。回転・基礎・部位のブロックは変えない。
  - 作り方 (`HouseDesigner`):
    1. 土台を、パターンの範囲から決める (幅・奥行き・階数・1階の高さ・柱の間隔・屋根・外観)。左右対称の家は、幅を奇数にし、柱を両端から数え、入口がまん中に来る幅にする。
    2. パーツを、作られる順 (翼棟 → 塔 → 小塔 → ポーチ → 出窓 → バルコニー → ドーマー窓 → 煙突) に置く。1 つのパーツを、場所と大きさを変えて何通りか試す。試すたびに、それまでの家の上に本当に作ってみて、次のものは捨てる:
       - ドーマー窓: その幅のどの列でも、屋根が壁の線から奥へ上がっていない (破風の面・寄棟の角) / 後ろの屋根がドーマーの棟より低い (屋根から突き出る)。
       - 翼棟: 屋根が本体の棟より高い。
       - バルコニー: 下に階がない。出窓: 階がない。家の中の煙突: 壁の内側に収まらない。
       - 入口と、その前の 3 ブロック (高さ 2) に何かを置く (t239: 地面の棟のテラスの縁がかかるのも)。
       - ポーチ・出窓・バルコニー・外の煙突が、家 (張り出した階・軒) にめり込む。
       - 前に置いたパーツのブロックを、「重なりの許容」より多く上書きする・消す (なし: 0、少し: 3%、多め: 10%)。
       残ったうち、上書きがいちばん少ないものを置く。左右対称の家は、パーツを鏡に映した対で置く (まん中のものは 1 つ。t239: 片流れの屋根の棟は、鏡に映しても同じになるよう、棟を壁と平行にする)。
    3. 家を 1 つ作るたびに 12 通り 作り、いちばんよいものを残す。よさ: 上書きの少なさ、パーツの数が決まりに近い、パターンの主役のパーツがある、パーツの種類が多い、屋根の線の高さが 1 つでない (棟より高い塔、低い翼棟)、プレビューできる大きさ (3 万ブロックまで) と地形を読める広さ。
    4. 同じ seed と決まりなら、同じ家になる。作るのは本体と別の処理 (メインスレッドを止めない)。
  - 塔の家の大きな塔も、半分ほどは尖り屋根 (低か中) になる (t239)。
  - 確かめ方 (開発用、t239): `./gradlew test --tests '*HouseSamplesTest' -PhouseSamples=<フォルダ>` で、パターン × 規模 × seed の家を PNG (正面と斜め 2 方向) と数字のテキストに書き出す。`-PhouseSamplePatterns=storybook,tower`、`-PhouseSampleSeeds=4`、`-PhouseSampleShape=21,13,3,5,6` (幅・奥行き・階数・1階の高さ・柱の間隔を手で決めた形のまま) も使える。
  - コマンド: `/proceduraltool random [any|cottage|townhouse|farm|manor|tower|hub|compound|plan|storybook] [parts] [seed]` (パターンを選んで作る / `parts` でパーツだけ / seed で同じ家をもう一度)。できたときのメッセージに seed が出る。
- **部位とブロック**: 柱 (茶のウール)・壁 (白)・床 (薄い灰)・屋根 (赤)・石 (灰)・梁 (橙、t190)・窓 (水色、t190)。`treetool.materials.house-*` で変えられる。画面の部位のアイコンでも選べる。
- 大きさは数字で決まる (基本ページの高さ・幅は使わない)。地形は、家と追加パーツが届く所まで読む (最大 32)。置くときの上限 (`max-blocks`) とプレビューの上限は、ほかと同じ。

## ロビー (t190、ロビー・スポーン (hub) の建築の「街並みの配置」と「広場と景観」)
nekorozv の依頼 t190 の ⑤ Organic Layout (高さ・幅・角度を変えた自然な街並み) と ⑥ Plaza & Landscaping (中央の広場・花壇・木・道・地形へのなじませ)。`LobbyShape`。クリックしたブロックの上が広場のまん中。
- **広場**: 半径 4〜20、丸 / 八角 / 四角。床 (広場の床の部位) に、縁と 4 ブロックごとのタイルの目地を道の部位で。
- **中央**: 噴水 (丸い水盤・まん中の柱・上の小さな水盤) / 台座 (2 段の段と上の 2 ブロック) / なし。
- **花壇**: 広場の縁に沿って、長さ 5・奥行き 3 の一段高い花壇 (縁と土)。家への道の上には置かない。広場の半径 7 以上。
- **家**: おまかせ生成で家の数だけ作り、それぞれ正面を広場のまん中へ向けて、まわりに並べる。
  - パターンは「家のパターン」(おまかせなら、ハブの家・組み合わせの家を中心に、町家・コテージ・塔の家をまぜる)。パーツの多さも選べる。
  - 並べ方: 家ごとに、正面が広場の縁から「広場から家まで」だけ離れる距離に置き、まん中から見た幅 (と両側に 1.5〜2.5 ブロックのあき) の扇形を取る。扇形は重ならないので、家どうしは重ならない。円に入りきらない家は建てない。余った角度を家の間に分ける。
  - **ばらつき** (0〜1): 大きければ大きいほど、家の大きさ (小・中・大のまじり)、広場からの距離 (+0〜3)、向き (±8 度)、家の間のあきが不ぞろいになる。0 なら同じ大きさで等間隔。
- **家への道**: 各家の入口の前から、広場のまん中へまっすぐ、幅 3 の道を広場まで。
- **木**: プロシージャルツールの木 (丸い樹冠 7 割・針葉樹 3 割、小さめ)。まず家と家のすきまのまん中、次にまわりのどこかに (t239: いちばん遠い家の少し先まで。地形を読む範囲の内側)。家から 4・広場と道から 3・ほかの木から 5 ブロック以内には植えない。
- **地形になじませる**: 広場と道の下を地面まで石で埋め (最大 10)、家の基礎を地面まで伸ばし、木は地面に植える。地形はまん中から 48 ブロックまで読む。
- 同じシードと設定なら同じロビー。プレビュー・生成・保存はほかと同じ。家の部位のブロックも、ロビーの部位と一緒に選べる (基本ページの部位、または `/proceduraltool block`)。

## 共通
- 置くのは空気と草花だけ (地形は置き換えない)。岩は、地形の斜面に合わせて、足元を地面まで伸ばします。
- 設定の保存は `/proceduraltool save <名前>` (画面からは保存できません)、読み込みは画面か `/proceduraltool load <名前>`。保存した「作るもの」も一緒に残ります。

# 🎮 制約付き音源（Limited Sound System）におけるゲーム音楽作曲・編曲技法フレームワーク

本資料は、最大同時発音数の限界、音の持続（サスティン）の欠如、および厳格な時間軸（グリッド）の制限を持つ音源環境において、極めてドラマチックで空間的広がりのあるゲーム音楽を構築するための音楽理論および編曲技術を体系化したものである。

---

## 1. 根本的な技術的制約とハッキング（疑似表現）手法

### 1.1 クロック同期とテンポの数理的アプローチ

特定のシステム（例：毎秒20回の固定シグナルなど）に縛られた環境では、テンポ（BPM）は自由ではなく、グリッドとの整数比によって決定される。

- **グリッド適合テンポ：** 1拍を何グリッド（ティック）で割るかによって、正確に同期するBPMが決定される。
  - 4ティック/拍 ＝ **BPM 150** （超高速戦闘・激闘に最適）
  - 5ティック/拍 ＝ **BPM 120** （ストーリーボス、王道のマーチ、決戦に最適）
  - 6ティック/拍 ＝ **BPM 100** （標準的なフィールド、探索に最適）
  - 8ティック/拍 ＝ **BPM 75** （静寂なダンジョン、環境音に最適）
- **リズムの拡張（ヘミオラとポリミドル）：** 均一なグリッドの中で「3連符」を疑似表現するため、8分音符3個のグループと2個のグループを組み合わせる（3+3+2のリズムなど）、あるいは4/4拍子の中で3拍子のパルスを走らせることで、システム上の硬直性を破壊し推進力を生み出す。

### 1.2 減衰音源における「疑似サスティン」と「空間表現」

音が鳴った瞬間に減衰し、音を伸ばせない音源において、リバーブやディレイなどのエフェクターを使わずに残響空間を構築する技術。

- **タイムディビジョン・ディレイ（疑似エコー）：**
  - **手法：** メロディ（主旋律）を配置した直後のグリッド（例：1拍半遅れ、または3ティック後）に、**「音量を元の1/2〜1/4に落とした全く同じノート」**を手動で配置する。
  - **効果：** 物理的な残響を使用せず、1〜2つの発音チャンネルだけで広大な洞窟や神聖な空間の残響をシミュレートする。
- **高速分散和音による「疑似パッド（和音の残像効果）」：**
  - **手法：** 同時発音数を節約するため、和音（コード）を同時に鳴らさず、16分音符の超高速アルペジオに分解してループさせる。
  - **効果：** 脳の聴覚残像により、単音の連続でありながら、背景で重厚なストリングスやシンセパッドが鳴っているかのようなコード感を錯覚させる。

## 2. 4つのカテゴリにおける音響設計と音楽理論

### 🌲 A. フィールド・環境（永続性と聴覚疲労の回避）

プレイヤーが数時間単位で滞在するため、耳への負担を最小限に抑えつつ、世界の広大さを提示する設計。

- **テンポ・リズム：** BPM 75〜100（ロー〜ミドル）。歩行に同期しやすい6/8拍子、または浮遊感のある4/4拍子。
- **重要要素と音楽理論：**
  - **モーダル・ハーモニー（Modal Harmony）：**
    トニック（主和音）への強烈な解決を意図的に避ける。**ドリアン・モード（Dorian）**や**リディアン・モード（Lydian）**を使用し、メジャーともマイナーとも言い切れない「どこまでも続く世界」を表現する（例：`Im - IV` のループ）。
  - **オープン・ボイシング（Open Voicing）：**
    音が密集すると制約下ではノイズになりやすいため、和音の構成音（ルートと5度、あるいは3度）を1オクターブ以上離して配置し、中音域に広大な「空隙」を作ることで聴覚疲労を防ぐ。
- **レイヤー構造：**
  1.  低密度なベース（2〜4拍に1打）
  2.  ポリリズムを用いた静かな対旋律（カウンター・メロディ）
  3.  空白の多い、引き算された主旋律

### 🏰 B. ダンジョン・閉鎖空間（不気味さと緊張の持続）

視界の狭さ、潜む罠、未知の恐怖を五感に植え付けるための音響設計。

- **テンポ・リズム：** BPM 70〜85（ローテンポ）。拍頭（1拍目）をあえて曖昧にするシンコペーション。
- **重要要素と音楽理論：**
  - **不協和音程（m2 / Triton）の配置：**
    ルート音に対して半音で隣り合う音（短2度: m2）や、最も不安定な音程（三全音: Tritone）を、非常に小さな音量のスタッカートで背景に執拗に鳴らし続ける。
  - **ゴースト・レスト（無音の戦術）：**
    メロディやベースを1小節丸ごとストップさせ、超高音の打楽器のワンショット（1打）の残響だけで引っ張る。プレイヤーの耳を「無音」に集中させ、緊張感を最大化する。
  - **フリジアン・モード（Phrygian）：**
    根音から半音上の音を多用する旋律により、ダークでエキゾチックな、逃げ場のない閉塞感を演出する。

### 🔥 C. 強敵・中ボス（激闘と推進力の最大化）

純粋な戦闘の興奮、手数の多さ、フィジカルな脅威をプレイヤーに伝える設計。

- **テンポ・リズム：** BPM 130〜160（ハイテンポ）。16分音符の裏拍を強調したドライブ感。
- **重要要素と音楽理論：**
  - **トニック・ペダルポイント（Tonic Pedal Point）：**
    コード進行がどれだけ変化しても、ベースラインだけは主音（ルート）を16分音符で高速連打（オクターブ跳躍）し続ける。これにより、圧倒的な「前進するエネルギー」と「緊迫感」が生まれる。
  - **ハーモニック・マイナー（Harmonic Minor）と装飾音：**
    クラシックの「宿命」を感じさせる和声的短音階を使用。さらに、メロディの頭に「超高速の前打音（グリッド限界の装飾音）」を挟み、音がアタック（攻撃）の瞬間に鋭く立ち上がるように補正する。
- **レイヤー構造：**
  1.  16分音符を埋め尽くすパーカッション・チェイン（スネア・バスドラの擬似ロール）
  2.  オクターブ・ドライブ・ベース
  3.  高速アルペジオ（疑似和音パッド）
  4.  主旋律と、それに激しく衝突する同音量の対旋律（対位法）

### 👑 D. ストーリーボス・決戦（神聖・悲壮・劇的文脈）

世界の命運をかけた決戦。単なる激しさ（C）を超え、ボスの背景や世界の崩壊という「エモーショナルな文脈」を構築する最高峰の音響設計。

- **テンポ・リズム：** BPM 110〜130。あえて強敵（C）よりテンポを落とし、ドッシリとした重厚感と威厳を演出する。3拍子（12/8拍子）による気高きワルツ調の採用も極めて有効。
- **重要要素と音楽理論：**
  - **ダイナミック・テクスチャ（点から面への変貌）：**
    - **イントロ・Aメロ（点）：** 高音域の「時計の針」のような無機質なスタッカートと、超低音の地鳴りベースの2層だけで開始。プレイヤーの孤独感と絶望感を演出。
    - **サビ（面）：** 16分の超高速アルペジオ（疑似パッド）と、全発音チャンネルを解放したカウンターポイント（対位法）が爆発し、一気に壮大なオーケストラへと変貌させる。
  - **静寂のインタールード（中盤の演出）：**
    楽曲の2/3が経過した時点で、すべての打楽器とベースを完全にストップ。1声（ソロの木管・ストリングス系音色）の非常に美しく切ないメロディだけを数小節響かせる（ボスの過去や世界の悲哀の表現）。この直後に全レイヤーを大サビで再解放し、カタルシスを最大化する。
  - **王道の悲壮進行とピカルディ終止：**
    `i - VI - III - VII`（小室進行の変形）や `VI - VII - Im` などの劇的進行を使用。メロディの最高音をコードの「9th」や「Major 7th」の切ない音に引っ掛け、救われなさを表現しつつ、ループの直前で一瞬だけメジャーコード（ピカルディ終止）に変調させ、かすかな「光・救い」を提示する。

# メニューの見た目 (menus/*.yml、t220)

ファストトラベルとダンジョンのメニューの見た目を、yml リポジトリの `menus/` で決めます。
- 決められるもの: 並び順、名前、名前の色、アイコン、説明の行、推奨レベル。
- ツールサイトの「メニュー」タブで編集します。
- 読み直しはほかのデータと同じです (起動・`/iruurpg reload`・yml の同期)。再起動は要りません。

見た目だけをここに置きます。次のものは、今までの場所のままです。
- ファストトラベルの地点がどこにあるか: ゲームの中で `/travel set` を使い、`travel/waypoints.yml` に入る。
- ダンジョンの中身: `dungeons/*.yml`。

ファイルが無いときや、書いていない項目は、今までどおりの見た目です (`gui/MenuLooks`)。

## menus/travel.yml
```yaml
title: ファストトラベル          # メニューの題
entries:                        # 地点の id ごと (travel/waypoints.yml の id)
  atras:
    order: 1                    # 並び順 (小さいほど先。書いていない地点は、そのあとに今までの順)
    name: アトラス村            # 名前 (書かなければ、地点の名前)
    color: aqua                 # 名前の色: ゲームの色の名前 (aqua、gold、green、dark_gray など) か #RRGGBB
    icon: ENDER_EYE             # アイコン (アイテムの名前)
    lore:                       # 名前の下の行 (距離・料金・「クリックで移動」の前)
      - 村の広場
unknown:                        # まだ見つけていない地点の見た目
  name: "???"
  color: dark_gray
  icon: GRAY_DYE
  lore: [まだ訪れていない]
```

## menus/dungeons.yml
```yaml
title: ダンジョン
entries:                        # ダンジョンの id ごと (dungeons/<id>.yml)
  cave:
    order: 1
    name: アトラスの洞窟
    color: green                # 書くと、入れないときも、この色
    icon: SPAWNER               # 書くと、入れないときも、このアイコン (準備中は灰色の染料のまま)
    lore: [アトラスの近くにある、小さな洞窟。]   # ダンジョンの説明の代わり
    recommended-level: 5        # 「推奨 LvN 以上」に出す数 (入れる条件は、dungeons の min-level のまま)
```

## 読めない値
- 知らない色・アイテム、整数でない order や recommended-level は、その項目だけ使いません。警告は reload-report.txt とサーバーのログに出ます。
- 読めないファイルは、まるごと使いません (今までの見た目)。
- プラグインは止まりません。

## 専用の見た目 (ui/*.yml、t291 の試し)
メニューの窓に、背景の絵と、スロットに貼る絵を付けます。今はメインメニュー (`ui/main.yml`) だけが使います。ほかのメニューは、`MenuSkins` の `title` / `dress` / `button` の 3 か所を呼べば使えます。
- **ファイル**: yml のリポジトリの `ui/<メニュー>.yml` と、その絵 (`ui/` の下の PNG)。読み直し (起動・`/iruurpg reload`・yml の同期) で読み、パック `iruuui.zip` を作り直します。中身が変わったら、ログイン中の人にも送り直します。見た目のあるメニューが 1 つもなければ、パックは作りません (前のパックは消します)。
- **背景** (`background`): 窓の左上から重ねる絵です。幅は 176、高さはチェストの 6 行ぶんなら上半分 125 (下のインベントリまで覆うなら 222)。256 x 256 まで。透明な所は、今までの窓の見た目が見えます。
  - 窓のタイトルの文字として出します。フォント `iruurpg:ui` の 1 文字 (U+E000〜) で、8 ピクセル左へ戻して、窓のいちばん上に合わせます (ascent 13)。
  - 窓のマス (行 r・列 c) は、絵の x = 7 + 18c、y = 17 + 18r からの 18 x 18 です。
  - **窓の外へはみ出す** (t292、`background-origin: [x, y]`): 絵の中で、窓の左上がどこかを書きます。絵は、窓の左へ x、上へ y はみ出して出ます (窓の角から外へ出る札など)。y は、絵の高さ - 13 まで。右と下へは、絵を大きくすればはみ出します。窓の外は押しても何も起きません (絵だけ)。
- **タイトル** (`title`、`title-color`): 背景の上に出す文字です。書かなければメニューのタイトル、`""` で文字なし。`title-x` (t293) で、文字の始まりを窓の左から何ピクセルにするかを変えられます (ゲームの決まりは 8。高さは変えられません)。
- **縁を消す** (`hide-frame`、初期値 true): パーツの外にあるメニューのガラス板 (縁) を外して、背景を見せます。
- **スロットに貼る絵** (`parts`): `slots` (`"19-20"`・`"12-14, 21"`・リスト) の四角を、1 マス 18 ピクセルで切って、それぞれのマスに貼ります。絵の大きさは、四角の 18 x 列数、18 x 行数ちょうどにします。
  - 1 マスの絵は、アイテム `STRUCTURE_VOID` に custom model data (7000000〜) を付けたものです。モデルはマスのふち (-1〜17) まで広がった平らな四角なので、隣のマスの絵とつながります。
  - **どのマスを押しても、`button` のマス** (書かなければ最初のマス) を押したのと同じになります。どのマスにも、そのボタンの名前と説明が出ます。
  - **ボタンを動かす** (t293): `button` を、パーツの外のマスにすると、そのボタンをパーツの場所へ動かしたことになります。元のマスは空になり、押しても何も起きません (別のパーツが元のマスを覆っていれば、そのパーツのまま)。メニューのコードを変えずに、見た目だけでボタンを並べ替えられます。
  - **マスの外へはみ出す** (t292、`overflow`): 絵を、パーツのマスの四角より、左・上・右・下へ何ピクセル大きくするか (`[左, 上, 右, 下]`、1 つの数なら 4 方向とも。15 まで)。絵の大きさは、その分だけ大きくします。はみ出した所は、端のマスの絵が受け持ちます (モデルの四角がそこまで広がる)。はみ出した所は、押しても反応しません。隣のマスのアイテムが後から描かれると、その下になります。
  - パーツのマスでも、マウスを乗せたときの白い光はマス 1 つぶんです (ゲームの決まり)。
- **試しの間** (`testers-only: true`): OP と、権限 `iruurpg.uitest` の人にだけ見えます。ほかの人には、今までのメニューのままです。`enabled: false` で、その見た目をやめます。
- 読めない所 (名前に大文字、マスの外、絵の大きさが合わない、ほかのパーツと重なる) は、その部分だけ使わず、警告を出します。プラグインは止まりません。
- パックが入っていない人には、背景が四角の文字に、パーツが空間構造ブロックの絵に見えます (試しの間は、OP だけ)。

# 画面効果 (screenfx/、t125)

クライアントのシェーダーで描く、画面全体の効果。ブルーム (明るいところが光ってにじむ、t125) と、暗くする (黒を重ねる、t126)。

## 使い方 (管理者)
- `/screenfx bloom [強さ] [秒] [対象]`: 出す。強さは 1〜255 (100 が標準、150 で強め)。秒を省くか 0 にすると、消すまで続く。対象はプレイヤー名かセレクター (`@a` など)。省くと自分。
- `/screenfx darken [強さ] [秒] [対象]`: 画面 (GUI 以外) に黒を重ねる。不透明度は 強さ ÷ 200 (100 で 0.5、200 以上で真っ黒)。シェーダーが効いているかを、見て分かるように確かめる用。
- `/screenfx bloom off [対象]`: ブルームを消す (`darken off` も同じ)。`/screenfx off [対象]`: その人の効果を全部消す。
- `/screenfx status [対象]`: いま何が出ているか。`/screenfx list`: 効果の一覧。
- プログラムからは `ScreenEffects#show(player, Effect.BLOOM, 強さ, tick)` / `hide` / `hideAll`。
- 見えるのは、サーバーのリソースパック (`iruumark.zip`) を入れている人だけ。シェーダーパック (Iris・OptiFine) を使っている人には出ない (バニラの描画が置き換わるため)。

## しくみ
サーバーは、クライアントでシェーダーを直接は動かせない。パックに入れたシェーダーが「見つけたら効果を出す」印 (マーカー) を、パケットでその人にだけ見せる。

1. **マーカー**: アイテムディスプレイ。`setVisibleByDefault(false)` と `showEntity` で、その人にだけ送る。大きさ 0 なので、世界には何も描かれない。発光していて、発光の色が `(177, 効果の番号, 強さ)` (効果の番号はブルームが 1)。大きさ (width/height) が 0 のディスプレイは画面外でも描画対象になるので、近くにあればよい (5 tick ごとに、8 ブロック以上離れたら連れてくる。別のワールドでは作り直す)。保存されない。
2. **コアシェーダー** `core/rendertype_outline` (発光の輪郭を描くもの) を置き換える。マーカーの色の頂点だけ、本当の位置ではなく、輪郭の絵の左下の 4×4 ピクセル (x = 4 ×(番号 − 1)) に描く。
3. **ポストチェーン** `post/entity_outline.json` を置き換える。発光しているものが 1 つでも描かれると、ゲームはこのチェーンを毎フレーム流す。
   - はじめに、左下のマーカーを、8×1 の小さな絵 (`iruu_fx_state`、番号 − 1 のピクセル = マーカーの色) に読み取る。
   - ブルーム: ゲームの画面 (`minecraft:main`) の明るい部分を取り出し、小さくしてぼかす (480×270 と 240×135 の 2 段)。強さ = 青 ÷ 100。
   - マーカーを消してから、ゲームと同じ輪郭を描く (マーカーが無いときの結果は、ゲームの輪郭と同じ。オフスクリーンの検証で差 0)。
   - 最後に、ブルームと輪郭と黒 (darken) を 1 枚の絵 (`final`) にまとめる。ゲームは、フレームの最後 (手・水・パーティクルのあと、GUI の前) にこの絵を画面に重ねる。ブルームは、重ねたときに画面へ足し算になるように、色と不透明度を決めている。黒は一番上。
4. 他の発光 (敵の Glowing、分身、スポナー探し) は、今までどおりの輪郭になる。マーカーの赤 177 は、チームの色 16 色のどれとも違う。

## 制限
- ブルームのもとになるのは、不透明な世界 (地形・エンティティ・空・太陽と月) だけ。水・半透明のブロック・パーティクル・雲・天気・手は、チェーンのあとで描かれるので、それ自体は光らない (ブルームは、その上にも重なる)。
- 明るさのしきい値は、シェーダーに固定 (輝度 0.65、柔らかさ 0.15)。昼の白いもの (雪・白い羊毛) も光る。
- 左下の 4×4 ピクセルに、ほかの発光の輪郭がちょうど重なったフレームは、効果が消えることがある (2 か所を読んでいるので、まれ)。
- `screen-effects.enabled: false` にすると、パックにシェーダーを入れず、`/screenfx` も使えない (起動時に読む)。

## 効果を足すとき
- `ScreenEffects.Effect` に番号 2〜8 で足す。マーカーはその番号の場所 (左下の x = 4 ×(番号 − 1)) に描かれる。
- `post/entity_outline.json` にパスを足し、`StateSampler` (= `iruu_fx_state`) の (番号 − 1, 0) を読む (a が 1 ならマーカーあり、b が強さ)。
- 新しいファイルは `markpack/ScreenShaders.FILES` に足す (全部そろわないと、パックに入れない)。

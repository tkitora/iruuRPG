# BGM Style Guide & Composition Prompt

BGMに共通する技術的特徴、音楽理論的アプローチ、および再現性のための手法をまとめた資料テンプレートです。

---

## 1. コアとなる技術的制約

### ① 音色の特徴（MIDI & SoundFontスタイル）

- **高品質すぎない、温かみのあるGM音源・レトロSoundFont感**
  - ストリングス（Strings）、ピチカート（Pizzicato）、ハープ（Harp）、ローファイな木管楽器（Oboe, Flute, Bassoon）が主軸。
  - シンセサイザー要素が入る場合も、90年代のハードウェアシンセや、チップチューンに近い「パルス波」「矩形波」がオーケストラと融合。
- **パーカッションのミニマリズム**
  - 過剰なハリウッド系シネマティックパーカッションは避け、ティンパニ、スネア、および「クリック音」「時計の針」「木製打楽器」のような、Note Blockを彷彿とさせる小気味よいアタック音を多用。

### ② アーキテクチャ（再現性を高めるトラック構成）

ClaudeでMIDIやMML、コード進行を生成する際は、以下の**4〜5レイヤー構成**を厳守してください。

1.  **Melody (主旋律):** フルート、バイオリン、または透き通ったシンセ。装飾音が多く、動きが激しい。
2.  **Counter-Melody / Arpeggio (対旋律・アルペジオ):** ハープやピチカート。空間の隙間を埋める16分音符のループ。
3.  **Pad / Strings (持続音):** 空間の広がりとコード感を支える、静かで広がりのあるストリングス。
4.  **Bass (低音):** チェロ、コントラバス、または重いシンセベース。ルート音をシンプルに刻む。
5.  **Percussion (打楽器):** トラックを推進する、軽快でタイトなリズム。

## 2. 音楽理論的アプローチ（コード進行・スケール・展開）

### ① テンポ（BPM）と拍子の法則

- **通常探索・街（Towns & Fields）:** BPM 90〜125（穏やか、または軽快な足取り）
- **緊迫・ダンジョン（Dungeons & Dark Areas）:** BPM 120〜140（焦燥感、16分の刻み）
- **ボス戦・終焉（Boss Battles）:** BPM 140〜175（非常に高速な変拍子、または圧倒的な疾走感）
- **拍子:** 4/4拍子が基本ですが、ボス曲や神秘的なエリアでは **3/4拍子、6/8拍子、または 7/8拍子などの変拍子** も使用。

### ② よく使われる表現・スケール

- **エオリアン（自然短音階） / ハーモニック・マイナー**
  - 王道ファンタジーの切なさとダークさを表現。
- **ドリアン・モード（Dorian Mode）**
  - 冒険感、神秘的な浮遊感を出すために多用。例：`Im - IV`（Dm - G）の繰り返し。
- **フリジアン・モード（Phrygian Mode）**
  - 砂漠や、崩壊した世界、邪悪な力が渦巻くエリアでのエキゾチックかつダークな表現。
- **クロマチック（半音階）の下行・上行**
  - ベースラインが半音ずつ下がっていく進行（ラインクリシェ）を、悲壮感や終末感の表現に使用。

### ③ 象徴的なコード進行パターン（Claude配信用レシピ）

- **王道ダークファンタジー（悲壮と決意）:**
  - `Im -> bVI -> bVII -> Im` （例：`Am -> F -> G -> Am`）
- **神秘的な浮遊感（ドリアン進行）:**
  - `Im -> IV -> bbVII -> Im` （例：`Am -> D -> G -> Am`）
- **終末・ボス戦（劇的展開）:**
  - `Im -> bVI -> bIII -> bVII` （例：`Am -> F -> C -> G` ＝ 16分音符のハープアルペジオを裏で高速回転させる）
  - `Im -> #IVdim -> IV -> bIII` （半音の揺らぎによる狂気）

## 3. iruuRPG の曲との突き合わせ (2026-10-30、BGM担当)

これは、一般的なゲーム音楽の**スタイルのテンプレート**で、ノートブロックの制約には触れていない。ノートブロック前提の資料は `docs/bgm-rules.md` (技術・用途別)、`docs/bgm-style-guide.md` (制約付き音源、`bgm_style_guide_02`)。

### 2つのガイドの食い違い (テンポ)

| 区分 | このガイド (01) | ガイド (02) | いまの曲 |
|---|---|---|---|
| フィールド | 90〜125 | 75〜100 | 100 / 75 |
| ダンジョン | 120〜140 (速い、16分の刻み) | 70〜85 (遅い、不気味) | 100 / 100 / 60 |
| ボス | 140〜175 | 130〜160 (ストーリーボスは 110〜130) | 150 |

ダンジョンの方向が逆。いまの曲は 02 寄り (遅く、静かに不気味)。01 の「焦燥感のあるダンジョン」は、遅い曲では出せないので、**追われる・罠の区画**のような用途なら速いダンジョン曲を別に作る手がある (どちらを採るかは用途で決める)。

### 使える BPM の注意 (02 の資料の数字の補足)
曲の1tick = 16分音符にすると、使える BPM は `TPS × 15` で、TPS が 20 の約数 (20, 10, 6.67, 5, 4 …) のものだけ: **300, 150, 100, 75, 60**。02 の「120 BPM (5ティック/拍)」と 01 の 120〜140 は、16分音符では**割り切れない** (120 BPM = TPS 8 = サーバーの 2.5 tick)。120 BPM にするには、1tick = 8分音符 (サーバーの 5 tick、TPS 4) にして、16分の細かさをあきらめる。165〜175 のような速さも、16分では作れない (150 か 300 BPM)。

### 構成 (5レイヤー)
旋律 / 対旋律・アルペジオ / パッド / ベース / 打楽器: いまの曲はおおむねこの形。パッドは持続音が無いので、アルペジオと打ち直し (`swell`) で代用している。

### 拍子
いまの曲は**すべて 4/4**。3/4・6/8・7/8 はまだ。作るなら、エンジンの小節の長さ (`BgmChannel.BAR_TICKS = 16`、`nbslib.BAR = 16`) が 16 固定なので、フェーズの小節頭でそろえる仕組み (`playSceneSynced`) と、曲の作成スクリプトに「1小節のtick数」を持たせる必要がある。

### スケールと進行
- 自然短音階 / ドリアン / フリジア: 使っている (Boss003 D マイナー、Dungeon003 C# ドリアン、Dungeon001 E フリジア風)。ハーモニック・マイナーは、まだ。
- `Im → bVI → bVII → Im` 系は、ボス曲で使っている。`Im → #IVdim → IV → bIII` (半音の揺らぎ) と、ベースの半音下行 (ラインクリシェ) は、まだ。

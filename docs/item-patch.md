# アイテムの yaml の更新を、ゲーム内のアイテムへ反映する (item patch)

アイテムの yaml (items/*.yml) が変わると、それまでに作られたアイテム (名前・説明文・見た目は作った時点のもの) を、新しい内容で作り直す。プレイヤーが拾い直す必要はない。

## しくみ
- **指紋 (fingerprint)**: 読み直しのたびに、各アイテムの定義から「素のアイテム」を作り、その中身のハッシュを取る。名前・説明文・素材・見た目・スキルの説明・クラスの印など、表示に効くものはすべて入る。
- **アイテムの印**: アイテム1個ごとに、作ったときの指紋を持たせる (PDC `iruurpg:item_rev`)。今の指紋と違うアイテムだけを作り直す。新しく作るアイテムには、作った時点で今の指紋が付く。
- **版**: 前回から指紋が変わった定義があると、全体の版 (整数) が 1 上がる。版と指紋は `plugins/iruuRPG/item-patch.yml` に保存する。プレイヤーは確認済みの版を持つ (プレイヤーの PDC `iruurpg:item_patch_version`)。

## いつ・どこを直すか
| いつ | どこ |
|---|---|
| yaml の読み直しで版が上がったとき (その場で) | マーケット (出品・買い注文・返却箱)、読み込み済みの個人倉庫 (開いている画面も)、オンラインのプレイヤー (インベントリ・防具・オフハンド・カーソル・エンダーチェスト・開いているチェスト類) |
| ログインしたとき (版ごとに1回) | そのプレイヤーの上と同じ場所。読み直しのときにその場で直したプレイヤーも、次のログインでもう一度確認する (不具合対策) |
| 個人倉庫をファイルから読んだとき | その倉庫 (直したら保存) |
| 置かれたチェスト・樽・シュルカーボックスなどを開いたとき | その中身 |

直さないもの: 額縁・地面に落ちているアイテム・シュルカーボックス (アイテム) の中身。これらはインベントリや開いた入れ物に入ったときに直る。定義が消えたアイテムは、そのまま残す。

## 残すもの (固有の情報)
作り直しても、次のものはすべて残す。
- PDC のすべてのキー (クラフトの強化 `bonus_stats`・属性の強化 `bonus_elements`、そのほか、ほかの機能が付けたキー)
- クラフト品のレア度 (PDC `iruurpg:rarity`。印のない古いクラフト品は、名前の `[**]` から読み、読めなければ強化の数から計算して、保存する)
- 個数
- エンチャント (定義の光沢 = LUCK は、定義に従う)

クラフト品は、作り直しても「クラフト品」の欄 (強化の一覧) が説明文に残る。

## 通知
直したアイテムがあったときだけ、チャットに1行 (「[アイテム] N 個のアイテムを、最新の内容に更新した。」)。サーバーのログにも、変わった定義と直した数が出る。

## テスト
`src/test/.../item/ItemPatcherTest` (`./gradlew test`。dev bundle のサーバーの本物のアイテム・PDC の処理で動く): 変わったアイテムだけが作り直されること、クラフトの強化・属性・レア度・ほかのキー・エンチャント・個数が残ること、古いクラフト品のレア度を名前から読むこと、版が変わったときだけ上がり、再起動のあとも保たれること。

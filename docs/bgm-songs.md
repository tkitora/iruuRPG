### モチーフ (引用・変奏の記録)
この曲が、大平原の地方テーマ。主題 = 5小節目の上行する形 (F#4 A4 D5 D5 E5 F#5: D の和音を駆け上がって、空に開く)。

| 場所 | 主題との関係 |
|---|---|
| A (5〜12) | 主題の提示 |
| A' (13〜20) | 前半 (1〜4小節) は主題をそのまま反復。後半は下行の新しい旋律 (F#5 E5 D5 A4) で応える |
| 静かな区間 (21〜28, 53〜60) | 主題の上行を「4度+3度」(F#4 B4 D5) の静かな形に変奏。低い音域で、ハープ / 小さなフルート |
| B (29〜36) | 主題の上行 (B4 D5 E5) を、長い音価で引き伸ばして高みへ (F#5 が頂点) |
| B' (37〜44) | B の旋律を8分音符で細かく変奏 |
| A (45〜52) | 主題の回帰 (原型) |
| コーダ (61〜64) | 静かな区間の断片 (D5 B4 F#4) を再現して、余韻を残す |

他の曲との関係: アトラスの洞窟の曲 (Field002) とボスの曲 (Boss001) の「アトラスのモチーフ」は、この主題を上下ひっくり返したもの (下の記録)。最初の街の曲 (まだ無い) が、この主題の上行を短調・ゆっくりで引用すると、「街を出て、空の下へ」という旅立ちが旋律でつながる。

### ログ (主人公の日記)
> 街の門を出て、最初の丘を越えた。風が草を渡っていく音がして、空はどこまでも青い。荷物は重いのに、足が勝手に前へ出る。振り返ったら、街は小さな屋根の集まりになっていた。あの宿の朝ごはんが、少しだけ恋しい。でも、それ以上に、この先に何があるのかを知りたくてたまらない。

### Dungeon001 (第2版)
- **拍を隠す**: ベースは毎拍ではなく 3 + 3 + 2 (ティック 0・6・12)。1つ目は弱く、裏拍が強い (ガイド02: ダンジョンは拍頭を曖昧に)。

- **ゴースト・レスト**: 間奏 (quiet) の6小節目は、全部止めて、高いピアノの1音とそのエコー2つだけ。
- **ラインクリシェ**: 間奏の頭で、Em を保ったままベースが E → D# → D → C# と下がる (ガイド01)。

依頼 t68(XavierEXE の楽譜をまとめた分析: 縦の密度・静と動の間・世界観に合わせた限定的な楽器選定・ノートブロックのアタックと減衰、とその提案3つ「引き算」「大胆なミュート」「楽器のリストラ」)にもとづく。生成: `tools/bgm/make_circuit_bgm.py`(`circuit_phase1.nbs` / `circuit_phase2.nbs`)。ボスはまだ決まっていない。
注意: 分析は依頼で送られた要約によるもので、楽譜そのもの(musescore のページは画像で、音符のデータが取れなかった)から数えたものではない。

|---|---|
| 曲名(仮) | Holy Circuit (Boss010) / …, Overclocked (Boss010) |
| 長さ・テンポ・調 | 2曲とも 2464 tick = 2:03(導入 64 tick + ループ 100小節)、**200 BPM**(20 ticks/秒、四分音符 = 6 tick、1小節 = 24 tick)、D ドリアン(フェーズ2は E♭ ドリアン)。第2版(t69: もう少し速く): 初版は 150 BPM・2:40 |
| 同じ曲として作った | テンポ・小節・和音・ループ位置が同じ(半音上)。テスト `theCircuitPhasesUseFiveInstrumentsFewRolesAndABreakWithoutBassAndDrums` |

### 1. 縦の密度: 役割は4つ、同時に最大5音
- ベース・リズムギター・リード・ドラムの4役だけ。**音域をきっちり分けた**(鳴る高さで): ベース F#1〜B2 未満(48 未満)、ギター F3〜F4(53〜66)、リード G4〜F5(67〜)。中域を埋めるパッドや裏メロは置かない。
- 実績: 同時発音は **最大5**(これまでの曲は 8 まで使う)。リードの長い音の打ち直しと、大きな場所での3度下のリードは、リード自身の分。

### 2. 楽器は5つだけ(両フェーズとも)
- ベース・ギター・プリング・キック・スネア。ハット、パッド、ベル、チャイム、フルートは使わない。
- 対比は**ギター(弾く弦、クラシック)× プリング(デジタルなエレピ)**。リードは長い音と順次・5度の跳躍の**賛美歌**(神聖)、ギターは 8分 → 3連(2 tick ごと、1秒に10音)の転がる落ち着かないピチカート(狂気)。

### 3. 静と動の間
- **曲の3分の2(ループの64小節目)で、ベースとドラムが8小節まるごと止まる**。プリングが賛美歌を休符を多くはさんでひとりで弾き、後ろの4小節でギターが1拍に1音で戻り、最後の曲の頭で全員が入る(テストで、この8小節にはプリングとギター以外が無いことを確認)。
- 各セクションの最後の小節は**ギャップ**: ドラムだけ(16分のロールが育つ)、またはリードの**単音1つだけ**(B のあと、ほかは全部止まる)。
- 導入(64 tick)はドラムのロール(16 tick)→ ベースとドラム → ギター(と単音)の順に足していく。アウトロ(12小節)は音を減らして薄くなり、最後はドラムだけでループに戻る。

### 4. アタックの明瞭さ
- すべての音は1回打つだけの短い音(ギターはピチカート、ベースは3発、ドラムはキックとスネアだけでハットなし)。リードの長い音は、4 tick ごとに弱く打ち直して、ぼやけさせない。

### 第2版: 速くした(t69)
- 依頼「circuit_phase1 をもう少し早く、それに基づいて要所の調整も」。2曲のテンポは同じでなければフェーズが切り替わらないので、**2曲とも 150 → 200 BPM**にした。1 tick = 16分の格子で出せるのは 150 と 300 だけで、その間は 20 ticks/秒で四分音符 = 6 tick(8分 = 3、3連 = 2)の **200 BPM** しかない(171 は8分が 3.5 tick になって割れない)。
- **要所の調整**: 16分は 1.5 tick で使えないので、ギターの16分は **3連(2 tick)の転がり**(1秒に10音、前と同じ速さ)にした。リードの音価、ベース・ドラムの位置は 1.5 倍に伸ばして、同じ形を保った。ブレイクの8小節は 12.8 秒 → 9.6 秒に縮む。長さが 2:40 → 2:03 に縮むぶん、アウトロを 8 → 12 小節にして 2 分(120 秒)を超えるようにした。長い音の打ち直しは 1拍(6 tick)ごと。
- **注意**: 1小節 = 24 tick は、ゲームの小節(16 tick)と合わない(4小節 = 96 tick = ゲームの6小節)。フェーズの切り替えは、ゲームの小節線 = 曲の拍の上ではなく、3回に2回は拍の途中に来る。2曲は同じテンポ・同じ位置なので、リズムは途切れないが、小節頭ではない。

### フェーズの違い
同じ5楽器のまま、半音上。キックが毎拍(B・C・最後の段)、ギターが A から転がる。

### 第2版(キラキラさせた): 初版の読み違い
ユーザーの指摘「もっとキラキラしてなかった? 寂しい感じはあったが、音が少なくて退屈なわけではない」。**初版は測り方を間違えていた**: 音数を**音全体**で数えたので、低音に支配されて「まばら(3音/秒、48〜72秒はほとんど無い)」と読んだ。**高い帯域(1〜5 kHz)だけで数えると、最初の小節から最後まで、毎秒 3〜5 音の安定した流れ**がある(`tools/bgm/analyze_audio_bands.py`。1〜2 kHz: 4.0音/秒、2〜3.5 kHz: 3.1、3.5〜5 kHz: 3.2。持続音のクライマックスの下でも毎秒 4〜5 音、3分の1の静かな部分だけ約 2音/秒)。エネルギーは低域が 71% で、1 kHz 以上は 8% しかなく静かだが、止まらない。これが「キラキラ」。

### モチーフ (引用・変奏の記録)
この曲が、大平原の地方テーマ。主題 = 5小節目の上行する形 (F#4 A4 D5 D5 E5 F#5: D の和音を駆け上がって、空に開く)。

| 場所 | 主題との関係 |
|---|---|
| A (5〜12) | 主題の提示 |
| A' (13〜20) | 前半 (1〜4小節) は主題をそのまま反復。後半は下行の新しい旋律 (F#5 E5 D5 A4) で応える |
| 静かな区間 (21〜28, 53〜60) | 主題の上行を「4度+3度」(F#4 B4 D5) の静かな形に変奏。低い音域で、ハープ / 小さなフルート |
| B (29〜36) | 主題の上行 (B4 D5 E5) を、長い音価で引き伸ばして高みへ (F#5 が頂点) |
| B' (37〜44) | B の旋律を8分音符で細かく変奏 |
| A (45〜52) | 主題の回帰 (原型) |
| コーダ (61〜64) | 静かな区間の断片 (D5 B4 F#4) を再現して、余韻を残す |

他の曲との関係: アトラスの洞窟の曲 (Field002) とボスの曲 (Boss001) の「アトラスのモチーフ」は、この主題を上下ひっくり返したもの (下の記録)。最初の街の曲 (まだ無い) が、この主題の上行を短調・ゆっくりで引用すると、「街を出て、空の下へ」という旅立ちが旋律でつながる。

### ログ (主人公の日記)
> 街の門を出て、最初の丘を越えた。風が草を渡っていく音がして、空はどこまでも青い。荷物は重いのに、足が勝手に前へ出る。振り返ったら、街は小さな屋根の集まりになっていた。あの宿の朝ごはんが、少しだけ恋しい。でも、それ以上に、この先に何があるのかを知りたくてたまらない。

**アトラスのモチーフ = E5 B4 G4 E4** (大平原の主題を上下ひっくり返した形。Field002、Boss001 と同じ)。この曲では、A の1小節目に付点の音価で出す (Field002 は4分音符、Boss001 は8分音符)。もう1つ、この曲だけの小さな動機 = **F→E の半音のため息** (A の4小節目: A4 F4 E4)。

### Dungeon001 (第2版)
- **拍を隠す**: ベースは毎拍ではなく 3 + 3 + 2 (ティック 0・6・12)。1つ目は弱く、裏拍が強い (ガイド02: ダンジョンは拍頭を曖昧に)。

- **ゴースト・レスト**: 間奏 (quiet) の6小節目は、全部止めて、高いピアノの1音とそのエコー2つだけ。
- **ラインクリシェ**: 間奏の頭で、Em を保ったままベースが E → D# → D → C# と下がる (ガイド01)。
- **三全音**: スウェル (C) の6小節目、B7 の上で F (電子) を、1回だけ、打ち直して保つ。
- **疑似パッド**: スウェルは、ピアノの16分音符のアルペジオ。**疑似エコー**: 旋律の4ティック後に弱い同音 (ピアノ)。

- **自然から電子へ**: 最初の A は自然 (ピアノ・ギター・ベース・ドラム) だけ。最初のサビで8ビットが旋律に重なり、**対旋律**のエレピが、旋律の長い音のすきまを走る。最後のサビで鉄琴のきらめきと、16分のスネアの連打 (チェーン) が入る。

### モチーフ
アトラスのモチーフ (主和音を3段で降りて主音へ) = D5 A4 F4 D4。A の1・9・15小節目と B の12小節目に、2曲とも同じ場所・同じ音価 (付点) で出る。ブリッジのソロは、モチーフを低く (フェーズ1) / 高く (フェーズ2) 出す。

### ログ (主人公の日記)
> 巨人の肩の上で、岩がきしむ音がした。足元が揺れて、石が、いま確かに、動いた。倒したと思った瞬間、核が青く光り、岩の割れ目から、見たことのない光が噴きだした。まだ終わっていない。

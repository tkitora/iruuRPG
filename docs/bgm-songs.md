# BGM 曲の記録

作曲のルールは [bgm-rules.md](bgm-rules.md)。曲ごとに、用途・長さ・構成・モチーフの関係・ログ・完成前チェックを残す。ゲーム内で鳴らして直す作業 (ルールの手順5) は手動。

## plains_adventure 「Under an Endless Sky」

| 項目 | 内容 |
|---|---|
| 用途 | 地域曲 (フィールド): 最初の街を出たあとの大平原。何度もループされる探索曲 |
| 場所・状況 | 大平原 (開始地点の街の外)。冒険の始まり、ワクワク、少しの郷愁、どこまでも続く青空 |
| 長さ | 64小節 = 2:34 (ルールの目安 2:30〜7:00)。ループ位置は5小節目 (イントロの4小節は最初の1回だけ) |
| テンポ・調 | 6.67 ticks/秒 (20/3、1tick = 16分音符)、100 BPM、4/4、D メジャー (アイリッシュ・ケルト風) |
| 主役楽器 | フルート (旋律)、ギター (指弾きのアルペジオ)。ハープ (オフビートのきらめき、静かな区間の旋律)、ベース、チャイム (高音の飾り)、ごく軽いバスドラムとハット (ボドラン風、A' から) |
| 音域 | すべて F#3〜F#5 (キー 33〜57) の中。バイオリンは無いので、第二フルートを旋律の3度下に置いて代わりにした (A' の後半と B 以降) |
| 同時発音 | 最大6音 (小節の頭)、いちばん忙しい1秒で15音、平均で毎秒8音 |
| ファイル | `src/main/resources/bgm/plains_adventure.nbs` (jar に同梱。サーバーでは `plugins/iruuRPG/bgm/`)。作る: `python3 tools/bgm/make_plains_bgm.py` |

### 構成
| 小節 | 区間 | 中身 |
|---|---|---|
| 1〜4 | イントロ | ギターと軽いベース。3〜4小節目にハープが主題の予告。1回だけ |
| 5〜12 | A | フルートが主題を出す。ギター・ベース |
| 13〜20 | A' | 主題の前半を繰り返し、後半は新しい下行の旋律。第二フルート (3度下) が後半に入り、ボドラン風の打楽器が始まる |
| 21〜28 | 静かな区間 | ハープが旋律。ギターとベースは小さく、打楽器なし。ここで起伏を落とす |
| 29〜36 | B | 展開。長い音価の高い旋律、第二フルート、ハープのきらめき、チャイム |
| 37〜44 | B' | B を8分音符で細かく変奏。最後は A の上の長い E で、主題の回帰を呼ぶ |
| 45〜52 | A (回帰) | 主題の回帰。いちばん厚い (旋律 + 3度下 + きらめき + 打楽器) |
| 53〜60 | 静かな区間 (再現) | 同じ旋律を、フルートで小さく。ギターとベースはさらに小さく |
| 61〜64 | コーダ | ハープとギターだけ。最後は A の和音 (属和音) で止まり、頭 (5小節目の D) へなめらかに戻る |

### モチーフ (引用・変奏の記録)
この曲が、大平原の地方テーマ。主題 = 5小節目の上行する形 (F#4 A4 D5 D5 E5 F#5: D の和音を駆け上がって、空に開く)。

| 場所 | 主題との関係 |
|---|---|
| A (5〜12) | 主題の提示 |
| A' (13〜20) | 前半 (1〜4小節) は主題をそのまま反復。後半は下行の新しい旋律 (F#5 E5 D5 A4) で応える |
| 静かな区間 (21〜28, 53〜60) | 主題の上行を「4度+3度」(F#4 B4 D5) の静かな形に変奏。低い音域で、ハープ / 小さなフルート |
| B (29〜36) | 主題の上行 (B4 D5 E5) を、長い音価で引き伸ばして高みへ (F#5 が頂点) |
| B' (37〜44) | B の旋律を8分音符で細かく変奏 |
| A (45〜52) | 主題の回帰 (原型) |
| コーダ (61〜64) | 静かな区間の断片 (D5 B4 F#4) を再現して、余韻を残す |

他の曲との関係 (案、まだ無い): 最初の街の曲が、この主題の上行を短調・ゆっくりで引用すると、「街を出て、空の下へ」という旅立ちが旋律でつながる。この大平原の主題を、別の地方で鳴らすときは変奏して使う。

### ログ (主人公の日記)
> 街の門を出て、最初の丘を越えた。風が草を渡っていく音がして、空はどこまでも青い。荷物は重いのに、足が勝手に前へ出る。振り返ったら、街は小さな屋根の集まりになっていた。あの宿の朝ごはんが、少しだけ恋しい。でも、それ以上に、この先に何があるのかを知りたくてたまらない。

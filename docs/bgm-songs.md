### モチーフ (引用・変奏の記録)
この曲が、大平原の地方テーマ。主題 = 5小節目の上行する形 (F#4 A4 D5 D5 E5 F#5: D の和音を駆け上がって、空に開く)。

| 場所 | 主題との関係 |
|---|---|
| A (5〜12) | 主題の提示 |
| A' (13〜20) | 前半 (1〜4小節) は主題をそのまま反復。後半は下行の新しい旋律 (F#5 E5 D5 A4) で応える |
| 静かな区間 (21〜28, 53〜60) | 主題の上行を「4度+3度」(F#4 B4 D5) の静かな形に変奏。低い音域で、ハープ / 小さなフルート |
| B (29〜36) | 主題の上行 (B4 D5 E5) を、長い音価で引き伸ばして高みへ (F#5 が頂点) |
| B' (37〜44) | B の旋律を8分音符で細かく変奏 |
| A (45〜52) | 主題の回帰 (原型) |
| コーダ (61〜64) | 静かな区間の断片 (D5 B4 F#4) を再現して、余韻を残す |

他の曲との関係: アトラスの洞窟の曲 (Field002) とボスの曲 (Boss001) の「アトラスのモチーフ」は、この主題を上下ひっくり返したもの (下の記録)。最初の街の曲 (まだ無い) が、この主題の上行を短調・ゆっくりで引用すると、「街を出て、空の下へ」という旅立ちが旋律でつながる。

### ログ (主人公の日記)
> 街の門を出て、最初の丘を越えた。風が草を渡っていく音がして、空はどこまでも青い。荷物は重いのに、足が勝手に前へ出る。振り返ったら、街は小さな屋根の集まりになっていた。あの宿の朝ごはんが、少しだけ恋しい。でも、それ以上に、この先に何があるのかを知りたくてたまらない。

## ダンジョンでの再生について (未対応)
アトラスの洞窟は「インスタンスダンジョン」で、入るたびにテンプレートのワールド (`dungeon_template_cave`) をコピーして、そのプレイヤー専用のワールドを作る。いまの BGM の範囲 (ボリューム) は、固定のワールド名で作るので、そのコピーのワールドでは鳴らない。ダンジョンで鳴らすには、範囲を「ダンジョンの id (例: cave) のコピーのワールド全体」に結びつける仕組みと、ボスが動き出したらボス曲に変える仕組みが要る (別の変更)。
